# SMTU Mobile
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Мобильный клиент СПбГМТУ на Flutter: расписание занятий по
учебным группам, вход в ИСУ, профиль студента, показ аудиторий на карте, уведомления и
автоматический будильник к первой паре.

Приложение работает офлайн: расписание и группа сохраняются на устройстве,
поэтому посмотреть занятия и поставить будильник можно без интернета.

> Проект учебный и не связан с администрацией университета. Расписание
> берётся с открытых страниц сайта вуза.

## Скачать и установить

Для обычных пользователей готовый файл приложения (APK) доступен в разделе **[Releases](../../releases)**.

1. Перейдите в раздел **Releases** и скачайте последний файл `app-release.apk`.
2. Откройте скачанный файл на телефоне.
3. Если Android попросит разрешение на установку из неизвестных источников — разрешите это для вашего браузера или проводника.
4. Нажмите «Установить».

> Приложение доступно только для Android.

## Возможности

### Расписание

- Поиск и выбор своей учебной группы.
- Расписание на текущую и следующую неделю с учётом числителя и знаменателя.
- Два режима просмотра: по дням и вся неделя целиком.
- Фильтр по неделям и подсветка текущего дня.
- Карточка пары: время, название, преподаватель, аудитория.
- Переход к карте аудитории по нажатию на номер.
- Обновление расписания жестом или кнопкой.

### Автоматический будильник

- Ставит системный будильник к первой паре каждого учебного дня.
- Будильники создаются при первом заходе в новую учебную неделю.
- Время можно изменить отдельно для каждого дня.
- Отдельный будильник можно удалить — он снимается и в системе, и в списке.
- Выключение автосоздания удаляет все созданные будильники.
- Дни без пар в список будильников не попадают.
- После срабатывания будильник снимается автоматически.
- Экран будильника показывается поверх блокировки, со звуком и вибрацией.

### Уведомления

- Напоминание перед первой парой каждого учебного дня.
- Настраиваемое время напоминания: от 0 до 180 минут до начала пары.
- Уведомление о ближайшем будильнике в шторке; нажатие открывает экран
  настроек будильников.

### ИСУ и профиль

- Авторизация в личном кабинете `isu.smtu.ru`.
- Профиль студента: учебные данные, фотография, разделы ИСУ.
- Скрытие чувствительных данных одним нажатием.
- Полная версия ИСУ во встроенном браузере с сохранённой сессией.
- Учётные данные хранятся в защищённом хранилище устройства.

### Карта аудиторий

- Интерактивная 3D-карта корпуса У с подсветкой нужной аудитории.
- Аудитория открывается по номеру из расписания.

### Офлайн-режим

- Группа и расписание кэшируются на устройстве.
- Без интернета доступны расписание и постановка будильника по сохранённым
  данным.
- Для действий, которым нужна сеть (вход в ИСУ, профиль, поиск группы),
  показывается сообщение об отсутствии подключения.

## Технологии

| Назначение | Пакет |
| --- | --- |
| UI | Flutter, Material 3 (`material_ui`) |
| HTTP и парсинг | `dio`, `html` |
| Авторизация и cookies | `dio`, `cookie_jar`, `dio_cookie_manager` |
| Безопасное хранилище | `flutter_secure_storage` |
| Локальные настройки и кэш | `shared_preferences`, `path_provider` |
| Уведомления | `flutter_local_notifications`, `timezone`, `flutter_timezone` |
| Состояние сети | `connectivity_plus` |
| Встроенный браузер | `webview_flutter` |
| Иконки | `flutter_launcher_icons`, `cupertino_icons` |

Системные будильники на Android реализованы нативно через
`AlarmManager.setAlarmClock` и MethodChannel `smtu/system_alarm`
(`android/app/src/main/kotlin/com/example/smtu_mobile/MainActivity.kt`).

## Структура проекта

```
lib/
├── main.dart                         # запуск, тема, стартовый экран и вход в ИСУУ
├── models/
│   ├── auth_result.dart              # результат авторизации
│   ├── schedule_models.dart          # группа, день, пара
│   └── student_profile.dart          # профиль и разделы ИСУ
├── parsers/
│   └── smtu_parser.dart              # разбор HTML расписания
├── screens/
│   ├── schedule_screen.dart          # расписание, выбор группы, карточка пары
│   ├── notification_settings_screen.dart
│   ├── profile_screen.dart           # профиль ИСУУ
│   ├── isu_profile_webview.dart      # полная версия ИСУ
│   └── room_map_screen.dart          # карта аудитории
└── services/
    ├── auth_service.dart             # вход, сессия, профиль
    ├── smtu_api.dart                 # запросы расписания
    ├── schedule_cache.dart           # кэш группы и расписания
    ├── connectivity_service.dart     # состояние сети
    ├── notification_service.dart     # напоминания, план будильников
    ├── system_alarm_service.dart     # MethodChannel к AlarmManager
    └── secure_cookie_storage.dart    # хранение cookies
android/                              # нативная часть: будильники и экран сигнала
```

## Сборка из исходного кода (для разработчиков)
### Требования

- Flutter SDK с Dart 3.14 или новее.
- Android SDK для сборки под Android.
- Устройство или эмулятор Android.

> Системные будильники реализованы только для Android. На iOS приложение
> запустится, но автоматический будильник работать не будет.

### Запуск

```bash
flutter pub get
flutter run
```

### Сборка APK

```bash
flutter build apk --release
```

Готовый файл: `build/app/outputs/flutter-apk/app-release.apk`.

## Разрешения Android

Приложение запрашивает:

- Доступ в интеренет.
- Звук и вибрация для будильника.
- Создание уведомлений.
- Возможность добавления будильника в системные «Часы».
